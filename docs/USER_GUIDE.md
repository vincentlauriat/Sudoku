# User Guide — Sudoku for macOS

Functional documentation: everything the app does, from a player's point of view.

## The game

Fill the 9×9 grid so that every **row**, every **column** and every **3×3 box** contains the
digits 1 through 9 exactly once. Some cells (the *givens*, shown in bold) are pre-filled;
they cannot be changed. Every puzzle generated by the app has exactly one solution.

## Starting a game

Pick a difficulty in the right-hand panel. A new grid is generated instantly:

| Level | Givens | Feel |
|---|---|---|
| Easy | 40 | Relaxed — many naked singles |
| Medium | 34 | Requires scanning rows/columns |
| Hard | 28 | Fewer freebies, more deduction |
| Expert | 24 | Sparse grid, sustained focus |

The status bar above the board shows the current level, elapsed time, and error count.

## Playing

**Selecting.** Click a cell, or move with the **arrow keys**. The selected cell is tinted
blue; its row, column and box peers are lightly shaded; all cells holding the same digit are
highlighted too — useful for scanning.

**Entering digits.** Type **1–9**, or click the number pad. Delete/Backspace (or the *Erase*
button) clears the cell. Givens are locked.

**Errors.** A digit that doesn't match the solution turns **red** and increments the error
counter. Two identical digits seeing each other (same row/column/box) also get a red conflict
tint. The wrong digit stays on the board until you correct it — the app never blocks input.

**Notes (pencil marks).** Toggle notes mode with the switch or the **N** key, then type digits
to jot small candidates in an empty cell. Typing a noted digit again removes it. When a digit
is correctly placed, that digit's notes are automatically wiped from all peer cells.

**Hint.** The *Hint* button fills the **selected** cell with its correct digit (if the
selected cell is a given or already correct, a random unsolved cell is used instead).
Hints don't count as errors.

## Auto-play — the app plays by itself

The **Auto** section of the panel is the app's signature feature:

- **Solve by itself** starts the show: the app picks a cell, highlights it, pauses, plays the
  correct digit, and moves on — choosing at every step the cell a human would look for
  (the one with the fewest possible digits). Any wrong digits you left on the board are
  corrected first.
- **Speed slider**: from 🐢 one move per second to 🐇 20 moves per second, adjustable live
  while it plays.
- **Pause** stops it instantly; press play to resume from the current position. You can even
  play some cells yourself while paused — the solver adapts.
- While auto-play runs, manual input is disabled (the board is the robot's).

Curious how it works under the hood? Read [AUTOPLAY.md](AUTOPLAY.md).

## Winning

When the grid is complete and correct, the timer stops and a victory overlay shows your level
and time. *New game* deals a fresh grid at the same difficulty.

## Keyboard reference

| Key | Action |
|---|---|
| 1–9 | Enter digit (or toggle note in notes mode) |
| Arrow keys | Move selection |
| Delete / ⌫ | Erase cell |
| N | Toggle notes mode |
| ⏎ | Confirm *New game* on the victory screen |
